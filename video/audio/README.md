# Music beds (original, synthesised)

Generated by `make-music.py` (numpy only; no samples, loops or soundfonts). Run
`video/.venv/bin/python video/audio/make-music.py` (needs numpy, soundfile, ffmpeg).
The WAVs are git-ignored (install bed is >25 MB); regenerate them with the script (deterministic).
Format: 48 kHz stereo 24-bit WAV, about -20 LUFS integrated, peaks about -8 to -9.5 dBFS.
Key: A minor / C major, soft pads + plucked arpeggio + gentle kick/hat. 1-4 kHz is dipped about 5 dB for voice.
Previews (20 s): `preview/music-launch-preview.m4a` (44-64 s, includes the lift), `preview/music-install-preview.m4a` (6-26 s).
